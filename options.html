YouTube Digest

Bring your own API keys

Keys stay in this Chrome profile and are sent only to Supadata and DeepSeek. This open-source extension has no developer server or analytics.

Transcript provider

Used to fetch timestamped YouTube subtitles. Create a Supadata account and key. Supadata generates the key during onboarding.

AI provider

YouTube Digest uses DeepSeek for overviews, explanations, translation, chat, and note polishing. Create a DeepSeek API key.

Used for overviews, explanations, translation, chat, and note polishing through OpenAI's chat completions API. Create an OpenAI API key.

Used for overviews, explanations, translation, chat, and note polishing through the Gemini API. Create a Gemini API key.

When you use AI features, the selected provider receives the video transcript and relevant video context. Review its terms and pricing before saving.

You can edit the prompt directly. Complete these three steps before copying:

  1. Open the extracted YouTube Digest project folder in your coding agent.
  2. Replace [PROVIDER] and [MODEL] with the service and model you want to use.
  3. Never include API keys in the prompt or chat. Enter them yourself after the code is ready.
