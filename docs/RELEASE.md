## YouTube Digest 本地增强版 2.0.0

桌面 Chrome 本地阅读工具：支持 B站、YouTube、字幕导入、主题笔记和视频专属讨论修订。

### 安装

下载附件 `youtube-digest-v2.0.0.zip` 并解压。在 `chrome://extensions` 开启开发者模式，选择“加载已解压的扩展程序”，加载包含 `manifest.json` 的文件夹。在 Settings 中填写自己的 AI API Key。B站和导入不需要 Supadata；YouTube 需要另配 Supadata Key。

### 主要功能

- 完整标签页阅读、本地历史和 Markdown 导出。
- 主题目标、核心要点、可复用流程、示例选择及操作细节提取。
- 基于字幕与笔记的讨论、时间戳引用、修订稿预览、手动应用和恢复上一版。

### 使用范围

仅桌面 Chrome。没有手机、抖音、音频转写、画面理解或云同步。AI 会将文字发送给所选服务并可能收费；本地记录不是加密密码库。字幕是否可取取决于平台及登录限制。保持阅读页打开，重要内容请导出备份。API/浏览器自动测试使用模拟服务，不等同于所有真实平台和模型均已实测。
