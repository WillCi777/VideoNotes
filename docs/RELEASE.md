## VideoNotes 2.1.0

VideoNotes（视频笔记），由 WillCi777 维护的桌面 Chrome 视频学习工具。

### 本次更新

- 仓库、插件名称、设置页面、导出署名统一为 VideoNotes。
- 保留原有 API 配置、本地历史与内部存储键；使用原安装目录更新有助于保留扩展身份。
- 保留 MIT 许可和原始项目版权。

### 安装

下载 `videonotes-v2.1.0.zip` 并解压。在 Chrome 扩展管理页开启开发者模式，选择“加载已解压的扩展程序”，加载包含 manifest.json 的目录。已有用户先导出重要笔记，再更新原目录、重新加载扩展并刷新阅读页。

配置自己的 AI API Key；B站和导入不需要 Supadata，YouTube 需要另配。支持视频字幕、主题笔记、讨论和修订预览/应用/恢复。本地记录不代表离线处理，AI 请求仍会发送文字并可能收费。

不支持手机、抖音、音频转写或画面理解。详情见仓库说明。
